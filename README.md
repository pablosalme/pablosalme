Monto sistemas de agentes de código.

Un orquestador por proyecto reparte el trabajo entre Claude Code, Codex, OpenCode y Grok. Cada agente va en su worktree. Lo que escribe un modelo lo revisa otro antes de integrarse.

Me interesa menos el modelo de turno que lo que hay alrededor: cómo se parte una tarea, quién revisa a quién y qué pasa cuando un agente se equivoca.

Lo último que he publicado es [t3-autopilot](https://github.com/pablosalme/t3-autopilot), un servidor MCP en pre-alfa. Le recomienda al orquestador de T3 Code qué proveedor, modelo y esfuerzo usar en cada tarea que delega. Solo recomienda: no lanza agentes.
